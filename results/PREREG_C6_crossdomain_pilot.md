## 0. 问题与要检验的命题

轴承上已确认（只在 CWRU 文件池内）：故障训练数据的**类内变异覆盖**（损伤尺寸）决定 −8 dB AWGN 下的崩溃主导类别——只用 0.007″ → IR；加入任一较大尺寸 → 离开 IR（E5：3/3 架构 ANY_LARGER_SIZE；C-INIT 下 wdcnn、drsn、三架构单尺寸结果重复）。类比例无作用。

**C6′（本试点检验的版本）**：在非轴承领域，固定样本预算、优化步数与类比例，只改变各类训练数据覆盖的**子类型**，强噪声下的主导类别（失效吸引子）
(a) 在同一覆盖条件内跨种子稳定；且 (b) 随覆盖条件改变而移动。

**不检验**：崩溃方向能否事先预测（C5 已证伪，这里只作 §7 的次要描述）；子类型与吸引子之间的“机制”；跨域方向是否相同（各领域的类没有对应关系）。

## 1. 领域与数据（两个，模态不同）

| | D1：心电（ECG） | D2：自然图像 |
|---|---|---|
| 数据集 | PTB-XL v1.0.3（PhysioNet，公开，CC-BY 4.0） | CIFAR-100（公开） |
| 选择理由 | 一维、与轴承同为时间序列，**可原样复用 `pbx` 的模型**；有“超类 → 子类”两级标注 | 模态完全不同；有“粗类 → 细类”两级标注，覆盖操控最干净 |
| 类（4 个，与轴承同数） | NORM（基准类，相当于轴承 Normal）+ MI、STTC、CD | 基准类 *large natural outdoor scenes* + *fish*、*flowers*、*vehicles 1* |
| 子类型（被操控） | 每个疾病超类内，按训练池中**单一超类、likelihood = 100** 的记录数排序取前 3 个子类 → a、b、c（规则先定，具体是谁由 §9 冒烟打印） | 每个粗类的 5 个细类按 CIFAR-100 官方细类编号升序，取第 1、2 个为 a、b，S_ALL 用全部 5 个 |
| 输入 | 导联 II，100 Hz，10 s → 1000 点，单通道，逐记录 z-score | 32×32×3，按训练集通道均值/方差标准化，**不做数据增强** |
| 切分 | 按官方 `strat_fold`（患者不相交）：1–8 训练池，9–10 测试；只保留单一超类记录 | 官方 train / test |
| 测试集 | folds 9–10 中 4 个超类的全部单一超类记录（含所有子类，自然构成） | 4 个粗类的官方测试图像（每类 500 张，含全部 5 个细类） |

测试集包含训练臂未见过的子类型——与轴承 E5 单尺寸臂相同（`VERDICT_E5.md` §2.4），照实报告。

## 2. 设计（每个领域相同）

**因子：覆盖（3 臂）**

| 臂 | 基准类 | 每个被操控类 |
|---|---|---|
| `S_a` | 230，取自全部子类 | 230，全部取自子类 a |
| `S_b` | 同上（同一批样本） | 230，全部取自子类 b |
| `S_ALL` | 同上 | 230，在全部子类间均分（ECG：a/b/c 77/77/76；图像：5 个细类各 46） |

- 预算：每类 230，共 920（与 E5 相同），类比例 1:1:1:1 固定
- 配对：基准类样本由 `rng([seed, 0])` 抽取，三臂共用；被操控类由 `rng([seed, class, subtype])` 无放回抽取，同一种子下 S_a 与 S_ALL 中子类 a 的样本是同一批的前缀
- **架构（每领域 3 个）**：D1 = wdcnn、drsn、lstm（E5 中覆盖效应成立的 3 个，`prior_screen.REGISTRY`，`in_channels=1`，K=4）；D2 = 4 层 CNN、ResNet-18（CIFAR 版 stem）、ViT-tiny（patch 4，depth 6，dim 192）
- **种子**：0–4（5 个，比 E5 的 3 个分辨率高）
- **实例数**：3 臂 × 3 架构 × 5 种子 = 每领域 45，共 **90**

## 3. 训练（与 `arm2x2.train_last` 一致）

AdamW(1e-3, wd 1e-4)、warmup 5 + cosine（按 epoch）、grad clip 1.0、batch 64、200 epoch → 每 epoch 15 步，共 **3000 步**；无噪声训练；类权重按训练集重算（此处为均衡）；**使用最后一轮权重，不做验证集选模**；`torch.manual_seed(20000 + seed)` 固定初始化，同一种子三臂初始化相同（沿用 C-INIT 约定），初始权重 SHA256 写入结果记录。

## 4. 评估

- SNR ∈ {+10, 0, −4, −6, −8, −10, −12} dB；每个 SNR 5 次噪声抽样，噪声种子 `1000 + 17·seed + r`（同一种子三臂同一组噪声）
- 噪声：**逐样本功率**的 AWGN（与轴承 `add_awgn_tensor` 的口径相同；该函数在外部包里，C6-P 重新实现并在 §9 冒烟中对一段 CWRU 窗口与原函数逐值比对）。图像在标准化后的张量上加噪，不截断
- 另加干净（无噪声）测试准确率
- **主结局**（与 `collapse_defs.py` 相同）：−8 dB 下实例的主导类别 = 5 次抽样各自最大类的众数；集中度 = 5 次最大类占比的均值；崩溃事件 = 集中度 ≥ 0.90（主）/ ≥ 0.60（次）

## 5. 判定（逐领域 × 逐架构，按顺序取第一个成立的标签）

记 `q(arm)` 为该臂 5 个种子主导类别的分布；`TV(x, y)` 为两臂分布的总变差距离（取值 k/5）；臂的**一致性** = 该臂众数类别占比。

| 顺序 | 标签 | 条件 |
|---|---|---|
| 1 | `NOT_LEARNED` | S_ALL 干净测试准确率 5 种子均值 < 0.40（机会水平 0.25） |
| 2 | `NO_COLLAPSE` | 全部 15 个实例中集中度 ≥ 0.60 的不足 60%（−8 dB）。此时**只看集中度、不看主导类别**，改用 −12 dB 重新检查一次；仍不足 → 该标签；够 → 后续判定全部在 −12 dB 上进行，并在判定中注明 |
| 3 | `UNSTABLE` | 3 臂中 ≥ 2 臂的一致性 < 0.8（即 < 4/5 种子） |
| 4 | `COVERAGE_SHIFT` | max(TV(S_a, S_ALL), TV(S_b, S_ALL)) ≥ 0.6 |
| 5 | `COVERAGE_INVARIANT` | 三对 TV 都 ≤ 0.2 |
| 6 | `MIXED` | 其余 |

附注（不改变标签）：若 TV(S_a, S_b) ≥ 0.6，加注 `+SUBTYPE_SPECIFIC`（吸引子取决于具体限制到哪个子类型，而不只是“是否受限”）。

**领域判定**：3 个架构中 ≥ 2 个为 `COVERAGE_SHIFT` → `SUPPORTS`；≥ 2 个为 `COVERAGE_INVARIANT` → `CONTRADICTS`；≥ 2 个为 `NOT_LEARNED` / `NO_COLLAPSE` → `UNINFORMATIVE`；其余 → `INCONCLUSIVE`。

## 6. 对项目的后果（预先约定）

| D1 × D2 | 下一步 |
|---|---|
| 两个都 `SUPPORTS` | C6′ 值得正式投入：写全规模确认预注册（更多子类型组合、加回比例因子、C-INIT 式复跑、第三领域如音频），目标 NMI / Nature Communications |
| 一个 `SUPPORTS`，另一个不是 `CONTRADICTS` | 加第三个领域（音频，如 Speech Commands 或 ESC-50）再决定，不据此改变投稿定位 |
| 任一 `CONTRADICTS` 且没有 `SUPPORTS` | C6′ 不成立：停止跨域线，MSSP 稿件维持“CWRU 内 + 方法学”定位，并可把本结果写成局限/讨论 |
| 两个都 `UNINFORMATIVE` | 试点设计失败（噪声不足以造成崩溃或模型未学会），不能对 C6′ 下结论；修订设计需新的预注册 |

无论何种结果，都**不写**“跨领域普遍因果效应”；试点只有 5 种子 × 3 架构 × 2 领域。

## 7. 次要（描述性，不参与判定）

1. **纯噪声探针**：每个实例输入 1000 个单位功率高斯噪声样本，记录预测分布的众数类；报告它作为 −8 dB 主导类别预测量的命中率，并与“常数预测器”（全部实例中最常见的主导类别）比较。属于 `VERDICT_thesis_falsified.md` 路径 B 的“含噪响应”量族，不是已被排除的决策头几何
2. −6 dB 与集中度 ≥ 0.90 两个口径下重复 §5
3. 各臂 × 架构的主导类别完整分布（不只是众数）、干净与 +10 dB 准确率
4. 吸引子是否落在基准类（NORM / scenes）的比例——对照轴承上 Normal 0/39（CWRU/JNU）与 PU Healthy 14/19 的不一致

## 8. 算力与时间估计

依据：`PREREG_TIMELINE.md` 中 2×2（60 个实例约 54 min）与 E5（189 个实例、3000 步约 6.7 h），即同一机器上一维模型约 1–2 min/实例。

| | 实例 | 估计单实例 | 小计 |
|---|---|---|---|
| D1 ECG（wdcnn / drsn / lstm） | 45 | 1–3 min（lstm 最慢，序列长 1000 与轴承 1024 相当） | ≈ 1.5 GPU·h |
| D2 图像（CNN / ResNet-18 / ViT-tiny） | 45 | 2–4 min（3000 步、batch 64、32×32） | ≈ 2.5 GPU·h |
| 评估（7 SNR × 5 次 + 探针） | 90 | < 1 min | ≈ 1 GPU·h |
| **合计** | 90 | | **≈ 5 GPU·h，按 10 GPU·h 预留** |

权重约 90 × < 50 MB（ResNet-18 最大，约 45 MB）≈ 1–2 GB。数据：PTB-XL 约 1.7 GB（只需 100 Hz 版本），CIFAR-100 约 170 MB。无 GPU 时 D1 可在 CPU 上跑（估计 10–20 倍时长），D2 不建议。

## 10. 局限（事前写明）

- 子类型 ≠ 损伤尺寸：ECG 子类（如下壁 / 前壁心梗）与 CIFAR 细类是“类内变异”的类比，不是严重程度梯度。即使 `SUPPORTS`，也只说明“覆盖决定吸引子”在形式上跨域，不说明机制相同
- 每个子类在 ECG 中混有患者、记录设备与标注者差异，覆盖因子同时附带这些差异（同轴承 §2 的“载荷多样性”），不再拆分
- CIFAR-100 粗类/细类的覆盖操控与 BREEDS（Santurkar et al., 2021）的子群体迁移设计相近；强噪声下“一律预测某一类”在图像鲁棒性文献中也有报道。**数据下载前需做一次撞车检查**，写入 `COLLISION_C6P.md`
- 5 种子 × 3 架构，TV 的分辨率为 0.2；试点只能发现大效应
- 图像领域架构与轴承不同（一维模型不能直接用于图像），“同一模型、不同领域”的比较只在 D1 成立
