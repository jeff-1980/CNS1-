# 静态编码手册 v1（2026-10-28 jeff 确认冻结）

依据：正式预注册 §6（`results/PREREG_AUDIT_main.md`）与试点 §3.1 的 S1–S8 条目。预注册只给了条目名，下面的类别是本手册补充的操作定义；已于 2026-10-28 冻结，之后的任何修改都写入 `results/DEVIATIONS_AUDIT.md`。

## 怎么编

- 篇目：`coding_sheet_blank.csv` 里的 80 篇（论文A 抽样框随机抽取，种子 20261017）。按 `draw_order` 顺序编，每篇一行。
- 两位编码员各自独立编全部 80 篇，**编完之前不看对方的表，也不看审计仓库里的任何结果**。
- 每格只填下面列出的代码（如 `B`），拿不准时填最接近的一项，并在 `coder_notes` 写原因。
- `evidence_location` 写依据所在位置（如 “§3.2 第 2 段；Table 4；代码 train.py:88”）。
- `ai_help` 写 AI 帮了什么（如 “LLM 摘录 §3”；没用就写 “无”）。AI 只能找段落、摘原文，**每一格的判断必须由编码员自己做**。
- 论文读不到全文时，`S1` 填 `X`，其余格空着，并在 `coder_notes` 写 “无全文”。
- 全文用材料包里统一的那份 PDF（`pdf/编号.pdf`）。002、068 是预印本，在 `coder_notes` 写“预印本”；页面有撤稿标记的论文照常编码，在 `coder_notes` 写“已撤稿”。
- 有代码链接的论文要打开仓库看训练脚本，S3、S4b、S8 依赖代码；没有代码的论文 S3 填 `N`，S4b 填 `N`。

## 条目与类别

**S1 切分单元**：训练集和测试集按什么分开（取头条结果所用的设置）
- `A` 窗口 / 样本级随机切分（同一段录音切出的窗口可同时出现在训练和测试中）
- `B` 按录音文件切分（同一文件只出现在一边）
- `C` 按轴承或部件切分（同一个轴承只出现在一边）
- `D` 按工况或域切分（跨转速、跨负载、跨设备、源域→目标域）
- `U` 未说明，无法判断
- `X` 无全文

**S2 验证集**
- `A` 没有验证集
- `B` 有独立验证集（与测试集不重叠）
- `C` 测试集兼作验证集（在测试集上调参、早停或挑模型）
- `U` 未说明

**S3 checkpoint 规则（看代码）**：最终报告的模型是哪一轮
- `L` 最后一轮
- `V` 验证集上最好（准确率最高或损失最低）
- `T` 测试集或目标域上最好
- `E` 早停（写明依据哪个集合时，在 notes 写出）
- `O` 其他
- `Q` 有代码但看不出
- `N` 没有公开代码

**S4a 正文是否说明选模规则**
- `Y` 正文明确写了报告的是哪一轮或按什么挑的
- `P` 只有含糊说法（如 “取最优结果”“训练至收敛”）
- `N` 没写

**S4b 正文与代码是否一致**
- `Y` 一致
- `D` 不一致（在 notes 写明各自是什么）
- `Q` 无法核对（正文没写或代码看不出）
- `N` 没有公开代码

**S5 种子数与方差**
- `S5_runs`：头条结果重复训练的次数，写数字；没说明写 `U`
- `S5_spread_reported`：`Y` 报告了标准差、方差、区间或箱线图；`N` 只报均值或单次；`U` 未说明

**S6 指标**
- `A` 只有准确率
- `M` 准确率加混淆矩阵
- `F` 含 F1、精确率、召回率等，但没有混淆矩阵
- `B` 同时有混淆矩阵和 F1 类指标

**S7 噪声协议**
- `N` 没有噪声实验
- `T` 训练用干净数据，测试加噪
- `B` 训练和测试都加噪
- `O` 其他噪声设置（如真实噪声、混合 SNR），在 notes 写明
- `U` 有噪声实验但协议说不清

**S8 可溯源性**：公开了哪些（可多选，用 `+` 连接，如 `C+W`）
- `0` 什么都没有
- `C` 代码
- `W` 训练好的权重
- `G` 训练日志或逐轮曲线
- `R` 原始结果文件（如逐次运行的数值）

## 一致性

两位编码员都编完后，由 Claude 计算每个条目的 Cohen's κ（S5_runs 用完全一致率）。κ < 0.6 的条目，按预注册把类别合并或改写定义后重编，改写前后的 κ 都报告。分歧条目由两人讨论定出最终值，讨论记录保留。
