# 第二编码员操作说明

感谢帮忙。这项工作是把 80 篇轴承故障诊断论文的实验做法，按统一的类别逐篇记下来，再和另一位编码员的结果比对一致性。你不需要懂深度学习的细节，照手册判断即可。

## 你收到的材料

| 文件 | 用途 |
|---|---|
| `CODEBOOK_v1.md` | 编码手册：每一项要填什么、有哪些选项。**先通读一遍再开始。** 用记事本或任意 Markdown 阅读器打开 |
| `coding_sheet_blank.csv` | 编码表，80 行，每篇论文一行。用 Excel 或 WPS 打开 |
| `pdf\` 文件夹 | 79 篇论文全文，文件名就是表里的编号（如 `009.pdf` 对应 draw_order 9）。003 没有全文 |

## 步骤

1. **先另存一份表**：打开 `coding_sheet_blank.csv`，另存为 `coding_sheet_你的姓名.xlsx`，之后只在这份上填。
2. **按编号逐篇编**：打开对应的 PDF，读方法和实验部分，按手册在 S1–S8 各列填代码（如 `B`、`V`、`Y`）。
3. **有代码链接的论文要看代码**：论文里如果给了 GitHub 等代码地址，打开仓库看训练脚本，S3、S4b、S8 要靠代码判断；没有代码的按手册填 `N`。
4. **每篇都填三列备注**：
   - `evidence_location`：依据在哪（如 “§3.2 第 2 段；Table 4；train.py 第 88 行”）；
   - `ai_help`：用了 AI 帮什么（如 “用 AI 找出实验设置段落”），没用写 “无”；
   - `coder_notes`：拿不准的地方和理由。002、068 是预印本，写 “预印本”；论文页面有撤稿标记的写 “已撤稿”。
5. **003 没有全文**：S1 填 `X`，其余空着，`coder_notes` 写 “无全文”。

## 规则

- **独立完成**：编完之前不和任何人讨论具体论文的判断，也不看别人的表。遇到手册没说清的情况，按最接近的选项填，在 `coder_notes` 写明，不要问别人怎么填。
- **AI 只能帮找、不能帮判**：可以用 AI 定位段落、翻译、摘出原文；但每一格填什么必须是你自己读完原文后的判断。不要把手册和论文交给 AI 让它直接填表。
- **拿不准时**：填最接近的一项，写清理由即可。不要求完美，分歧会在两人都编完后讨论解决。
- 不需要上网找额外资料，只用论文全文和论文里给出的代码链接。

## 工作量与交付

- 每篇大约 10–20 分钟，有代码的论文会久一些；80 篇合计约 15–25 小时，可以分几次做。
- 编完后把填好的表发回给王老师。之后两人会各自拿到对方的结果，对分歧的条目一起商量定稿。
