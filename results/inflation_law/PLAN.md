# 选模虚高定律：分析计划（2026-11-02，运行前提交）

jeff 2026-11-02 决定做这一项（“做定律”）。数据是已有的 38 个对象、88 组、880 次运行的逐轮曲线（`results/main_objects/protocols/*.json` 的 `acc_curve`），不新跑任何训练。注意：H-A2（best_rep − last 与余量 h 的 Spearman ρ = 0.74）已经看过，所以本计划只对**定量公式**做事前声明，不把方向性结论当作新发现。

## 1. 模型

把一次运行在报告集上的逐轮指标看成“平台值 + 波动”：后段第 k 轮 c_k = μ + σ·z_k。在报告集上取最大值（best_rep）相对最后一轮（last）的期望差为

  G = E[max_k c_k − c_E] ≈ σ · e(K)

其中 e(K) 为 K 个独立标准正态的期望最大值（K = 平台段轮数），即“从 K 次噪声里挑最高”的选择偏差。

σ 分成两部分：
- 测试集抽样噪声 σ_s = sqrt(h(1−h)/n)，h = 1 − μ（余量），n = 测试集样本数；
- 模型权重逐轮抖动带来的额外波动，用过离散因子 φ = σ / σ_s 表示。

**定律形式**：G ≈ φ · sqrt(h(1−h)/n) · e(K)。若 φ 在对象之间大致稳定，则虚高由余量 h、测试集大小 n、可选轮数 K 三个可事先知道的量决定：余量越大、测试集越小、轮数越多，虚高越大。

## 2. 量的估计

- 平台段：曲线后一半的轮次（k > E/2）；K = 平台段轮数；μ = 平台段均值，h = 1 − μ。
- σ：平台段去趋势后的标准差，用一阶差分估计 σ̂ = SD(Δc)/√2，减小慢漂移的影响。
- n：由指标取值的最小间隔反推（取值都是 1/n 的整数倍时成立）。能反推的对象约 25 个（`n_infer.csv`）；F1、多次平均等指标反推不出 n，这些对象只参加检验 B，不参加检验 C。
- e(K)：数值积分精确计算。

## 3. 检验（事先声明的判据）

**检验 A：内部一致性（σ 与 K 已知时，公式能否预测 G）**
- 用种子 0–4 估计每组的 σ̂ 与 K，预测种子 5–9 的组均 G（样本外）。只有 5 个种子的组用留一种子法。
- 判据：组层面 log(预测 G) 对 log(观测 G) 的回归，校准斜率在 0.8–1.25 之间，且 R² ≥ 0.5。观测 G = 0 的组用 G + 0.01 pp 取对数，另报不取对数的 Spearman。

**检验 B：σ 是否主要由余量决定**
- 组层面 log σ̂ 对 log sqrt(h(1−h)) 的回归斜率与 R²。斜率接近 1 说明波动随余量按抽样噪声的形状变化。

**检验 C：零参数定律（只用 h、n、K，加一个全局常数 φ）**
- 在能反推 n 的对象上，按对象留一估计全局 φ（取其余对象 φ 的中位数），预测留出对象各组的 G。
- 判据：校准斜率 0.8–1.25 且 R² ≥ 0.4。报告 φ 的分布（中位数与四分位距）。

**结论规则**
- A 和 C 都通过：写成“选模虚高可由余量、测试集大小和可选轮数预测”，作为 NC 版本的主结果。
- A 通过、C 不通过：公式成立但需要逐组的波动幅度，作为 MSSP 稿件的一节，不构成定律。
- A 不通过：模型不成立，如实报告，不再调整模型形式。
