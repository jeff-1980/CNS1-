# 预注册 WP2：PU 损伤程度构成复验（CWRU 2×2 结论的外部检验）

> 2026-09-25，写于任何 WP2 训练之前。规划：`strategy/subjournal-plan.md` v11.2 §4 WP2。碰撞检查：`results/COLLISION_WP2.md`（未命中，G2 维持暂通过）。
> 训练代码：`code/pu_wp2.py`（训练协议沿用 2×2：固定步数、最后一轮权重、匹配样本预算）。

## 1. 要检验的问题

CWRU 2×2（`VERDICT_2x2.md`）：故障训练数据**只含最小损伤尺寸**时，wdcnn / drsn 在 −8 dB 下崩向 **IR**；覆盖**全部尺寸**时崩向 **OR**；类别比例不起作用。
WP2 问：在 PU 上，把故障类训练数据从**只含损伤程度 1**（extent 1）改为**程度 1 + 程度 2 混合**，−8 dB 下的崩溃靶标是否朝 CWRU 的方向移动（IR 占比下降）。

## 2. 轴承与损伤程度（逐个核对）

程度来源：本地 PU 各轴承说明 PDF（`data_pu/*/K*.pdf`，"Extent of damage" 字段；解析结果 `tmp/wp2/pu_extent_pdf.json`）。KA04、KA15 本地没有 PDF，取自已发表的 PU 数据表（arXiv 2003.03315 表 3：KA04、KA15 均为 Level 1）。

| 块 | 类 | 程度 1 | 程度 2 |
|---|---|---|---|
| 真实损伤（R，**主分析**） | OR | KA04（疲劳点蚀，单点）、KA22（疲劳点蚀，单点） | KA16（疲劳点蚀，**重复**） |
| | IR | KI21（疲劳点蚀，单点）、KI14（疲劳点蚀，多处） | KI18（疲劳点蚀，单点） |
| 人工损伤（A，**补充**） | OR | KA05（电刻）、KA07（钻孔） | KA03（电刻）、KA08（钻孔） |
| | IR | KI03（电刻）、KI05（电刻） | KI08（电刻） |
| 两块共用 | Healthy | K001、K002 | — |

## 3. 臂（每臂每个故障类恰好 2 个轴承，每个轴承 600 个训练窗；Healthy 两个轴承各 600 个）

| 臂 | OR | IR | 说明 |
|---|---|---|---|
| R-L1 | KA04 + KA22 | KI21 + KI14 | 只含程度 1 |
| R-L12a | KA22 + **KA16** | KI21 + **KI18** | 各类保留一个程度 1，换入程度 2 |
| R-L12b | KA04 + **KA16** | KI14 + **KI18** | 保留另一个程度 1 轴承（个体对照） |
| A-L1 | KA05 + KA07 | KI03 + KI05 | 只含程度 1 |
| A-L12a | KA05 + **KA08** | KI03 + **KI08** | 电刻 L1 + 钻孔 L2 |
| A-L12b | KA07 + **KA03** | KI05 + **KI08** | 钻孔 L1 + 电刻 L2 |

- 每臂训练集 = 3 类 × 1200 = 3600 窗，类别 1:1:1，**不用类权重**
- 配对：同一个种子下，同一个轴承在不同臂中抽到的窗**完全相同**（抽样随机数只由种子与轴承代码决定）；Healthy 在所有臂中相同

## 4. 数据

- 工况 N15_M07_F10，每个轴承 20 个文件，`vibration_1` 通道，窗长 1024、步长 512、逐窗标准化（与 `pu_splits.build_pu_time_splits` 相同）
- **同个体时间切分**（PU 跨个体切分不可学，见 `pu_splits.py` 说明）：每个文件前 60% 为训练池；隔 1024 样本后的 20% 不用；再隔 1024 样本后的剩余部分为测试池
- **共同测试集（每块一个，所有臂共用）**：块内全部 8 个轴承的测试池；每个故障轴承取 300 窗，每个 Healthy 轴承取 450 窗（每类 900，共 2700），随机种子 42。测试集包含训练中未见过的轴承（R-L1 没见过 KA16、KI18），这是有意的：−8 dB 下的靶标是模型的性质，不依赖具体输入

## 5. 训练（所有臂一致）

- 固定 3000 步，batch 64，AdamW（lr 1e-3，wd 1e-4），梯度裁剪 1.0，**按步**的学习率曲线（前 5% 线性预热，其后余弦衰减），无早停、无选模，**用最后一步的权重**
- 架构：**主分析** wdcnn、drsn、lstm；**单列** cnn1d、transformer（只在 R-L1 与 R-L12a 两臂运行）
- 种子 0–4。共 6 臂 × 3 × 5 + 2 × 2 × 5 = **110 个实例**
- 评估：SNR ∈ {10, 0, −4, −6, −8, −10, −12} dB，每档 5 次独立噪声抽样，取靶标众数（与 2×2 的 `evaluate` 相同）

## 6. 主分析（真实损伤块 R；判定 WP2 是否成立）

对每个主分析架构 a，在 −8 dB 下：
- P_IR(臂) = 该臂 5 个种子中靶标为 IR 的比例
- **Δ_IR(a) = P_IR(R-L1) − ½[P_IR(R-L12a) + P_IR(R-L12b)]**（CWRU 方向为正）
- 95% CI：在臂内按种子有放回重抽（10000 次）
- 架构 a 判为 **"CWRU 方向移动"**：Δ_IR ≥ 0.20 且 CI 下限 > 0，并且 L12a 与 L12b **分别**相对 L1 的差都 > 0

| 标签 | 条件 |
|---|---|
| **WP2_PASS** | 3 个主分析架构中 ≥ 2 个判为 CWRU 方向移动 |
| **REVERSED** | ≥ 2 个架构 Δ_IR ≤ −0.20 且 CI 上限 < 0 |
| **INDIVIDUAL** | ≥ 2 个架构中，L12a 与 L12b 相对 L1 的差符号相反且绝对值均 ≥ 0.20（靶标由保留哪个轴承决定，而非程度） |
| **NO_SHIFT** | ≥ 2 个架构的 Δ_IR 的 CI 完全落在 (−0.20, 0.20) 内 |
| **INDETERMINATE** | 其他 |

**WP2 在规划中记为 ✓ 当且仅当真实损伤块为 WP2_PASS。** 人工损伤块用同样的规则计算，只作补充，不能单独使 WP2 成立。

## 7. 次要分析（只描述，不参与判定）

- Δ_OR（OR 占比的变化，CWRU 方向为负）
- 非方向性：各臂 −8 dB 靶标分布（含 Healthy）；若 L1 与 L12 的众数靶标不同但不是 IR→OR，照实报告为"其他方向的移动"
- 只计浓度 ≥ 0.90 的实例；−10、−12 dB 的同样统计
- +10 dB 准确率（可学性检查）：某臂某架构均值 < 0.90 → 该单元标注"未学会"，仍然报告
- cnn1d、transformer 的 R-L1 vs R-L12a

## 8. 事前已知的局限（与结果同等重要）

1. **真实损伤块每类只有 1 个程度 2 轴承**（KA16、KI18）。WP2_PASS 只能说"换入一个程度 2 的轴承使靶标朝 CWRU 方向移动，且与保留哪个程度 1 轴承无关"，**不能**把效应归因于"程度"本身：程度与 KA16、KI18 的个体特性不可分。KA16 还是重复损伤（R），另有损伤组合的混杂
2. 人工损伤块的 IR 只有 KI08 一个程度 2 轴承；OR 有 2 个（KA03、KA08），方法与 L1 交叉配对
3. PU 为 3 类（无 Ball），与 CWRU 的 4 类不同；"CWRU 方向"只定义为 IR 占比下降
4. 同个体时间切分：测试窗与训练窗来自同一批轴承的不同时间段
5. 每臂每架构 n = 5；主判定按架构计数，没有跨架构合并的统计检验

## 9. 事前预期（写下来，便于事后对照）

不确定。PU 在 paperB 协议下的崩溃靶标以 Healthy 为主（`pu_fine_snr.json`：Healthy ×14），因此 −8 dB 下 IR 占比可能在所有臂都很低，结果落入 NO_SHIFT 或 INDETERMINATE 的概率不小。
