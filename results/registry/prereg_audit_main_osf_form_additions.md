# OSF 2tqv6 表单里比冻结文件更具体的规定

OSF Preregistration 模板逐栏填写时（2026-10-19，登记之前、任何正式阶段数据之前），下列内容比 `results/PREREG_AUDIT_main.md` 写得更具体。它们随 OSF 2tqv6 一起登记，与冻结文件同样有约束力；冻结文件本身未改，SHA-256 不变。

1. 缺失数据：崩溃的运行用同一种子重跑一次，再失败记为缺失；组内剩余种子 ≥ 5 才进入 H-B 分析；< 5 但 ≥ 2 时只保留在描述性结果中；逐 epoch 记录不完整或未通过核对的运行按缺失处理；不做插补。
2. H-A2 的 Holm 校正：单侧 bootstrap p = 10 000 次对象簇 bootstrap 中 rho ≤ 0 的比例；四个主检验 Holm 校正后 p < 0.05 才算支持；同时报告百分位 95% CI。
3. H-B2 的 p 值：(1 + #{C_perm ≥ C_obs}) / 10 001；只含作者规则不是最后一轮、且有 ≥ 2 个方法组的对象。
4. 对照与检查：
   - 每次运行的最后一轮记录必须与作者代码自己的最终输出一致，否则剔除并修正记录方式；
   - 每个代码库家族的第一个对象做一次有/无额外评估的隔离检查，超出 GPU 非确定性的差异时改为离线评估逐 epoch 检查点；
   - 作者规则就是最后一轮的对象是阴性对照（I = 0）；
   - 用正式阶段代码重算试点 P3，必须复现 0→3 任务 6.5–8.6 个百分点的虚高，才开始正式分析。
5. Wilcoxon 检验的稳健性：|偏度| > 1 时另报符号检验，仅作敏感性分析。
6. Wilcoxon 在 n ≤ 25 时用精确 p 值，丢弃零差值。
7. 预计数据收集时长约 2–3 个月。
