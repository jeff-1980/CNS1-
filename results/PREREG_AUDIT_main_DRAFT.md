**可行性下限**：可运行对象 < 15 时，仍按本方案分析与报告，但在摘要中写明检验力不足。

## 3. 测量

**3.1 每个对象跑什么**：论文头条表格对应的配置；最多 4 个方法组（超过时取论文正文强调的 4 个，冻结前不能预知的，在跑之前写入对象登记表并提交 commit，再开跑）。每组 **10 个种子**（作者有种子机制时用种子 0–9；没有时做 10 次不设种子的重复）。数据、切分、轮数、超参一律用作者默认；泄漏只编码不修复（含 CWRU 99.mat 读错键的情况，记录其读到的键）。

**3.2 逐 epoch 记录**：用与试点相同的方式（适配器或不改源码的钩子，RNG 与模型模式隔离），记录选模集与报告集（论文报告的数据划分）上每轮的准确率与损失。最后一轮的记录必须与作者代码自己的最终结果核对。

**3.3 协议**：
- `author`：作者代码实际使用的选模规则；
- `last`：最后一轮；
- `best_rep`：在报告集上第一个严格最大值（反事实上界）；
- `minloss`：选模集损失最小的一轮（无选模集时用报告集）；
- `budget50`：第 ceil(0.5·E) 轮。

**3.4 任务余量**：h = 1 − 该组 `last` 协议下报告集准确率的种子均值。

## 4. 主假设与检验（验证性）

单位：对象 o 的方法组 g（o×g）。对象层汇总取组的均值。全部检验预先单侧或双侧如下写明，α = 0.05；H-A1、H-A2、H-B1、H-B2 四个主检验用 Holm 校正。

**H-A1 虚高存在**：在作者规则不是 `last` 的对象中，对象层虚高 I_o = mean_g mean_seeds(author − last) 的中位数 > 0。Wilcoxon 符号秩检验（单侧）。同时报告 I_o 的分布与 bootstrap 95% CI。

**H-A2 虚高随余量增大**：在全部对象的 o×g 单位上，`best_rep − last` 与 h 的 Spearman 相关 ρ > 0。以对象为簇做 bootstrap（10 000 次），95% CI 下界 > 0 即支持。另报 `author − last` 的同一分析（只含作者规则不是 `last` 的对象）。

**H-B1 方差压缩**：每个 o×g 计算 r = SD_author / SD_last（两者都为 0 的单位剔除；只有 SD_author 为 0 时记 r = 0）。对象层取 log r 的中位数（r = 0 用 log 0.01 截断），在作者规则不是 `last` 的对象中，其中位数 < 0。Wilcoxon 符号秩检验（单侧）。`best_rep` 对 `last` 的同一分析在全部对象上报告。

**H-B2 显著性改变多于随机**：在每个对象头条表格的全部组对上，按配对 t 检验（按种子序号配对，α = 0.05）分别在 `author` 与 `last` 下给出判定（显著正 / 显著负 / 不显著），统计改变数（新增、消失、反转之和），全体对象求和。零分布：对每个种子以 0.5 的概率交换该种子在 `author` 与 `last` 下的值（同一种子内所有组同时交换），重算判定改变数，10 000 次。观测值超过零分布的 95% 分位即支持。只含作者规则不是 `last` 的对象。
