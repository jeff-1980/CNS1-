# 预处理与噪声协议核对（审稿意见 5，2026-09-25）

来源：`code/pbx/data/splits_v2.py::_segment_and_window`、`code/pbx/data/noise_augment.py::add_awgn_tensor`、`code/arm2x2.py::evaluate`、`code/pu_wp2.py::evaluate`、`code/e5_size_id.py`。

| 项 | 实际做法 |
|---|---|
| 顺序 | 原始信号 → 切窗（1024 点，步长 512）→ **每个窗口单独 z-score**（窗口自身均值 / 标准差，不用训练集统计量）→ 加噪 → 模型。加噪后**不再**归一化 |
| 加噪 | `x + N(0,1)·sqrt(P_x / 10^(SNR/10))`，P_x 为该窗口（已归一化）的均方值 ≈ 1 → 各窗口在归一化尺度上的噪声标准差近似相同（≈ 10^(−SNR/20)），各数据集之间也相同 |
| 同一种子的噪声实现 | 评估时噪声种子 = `1000 + 17·seed + r`（r = 0…4），测试集与 batch 划分在各干预臂间相同 → **同一种子在所有臂中使用完全相同的噪声张量**（2×2、E2、E5、WP2）。WP5 / WP5b 使用 `5000 + 17·seed + r`，同样跨条件共享 |
| 采样率与窗口时长 | CWRU 驱动端 12 kHz → **85.3 ms**（约 2.5 转，1730–1797 rpm）；PU 64 kHz → **16.0 ms**（1500 rpm 下约 0.4 转；900 rpm 下约 0.24 转）；JNU 50 kHz → **20.5 ms**（600 rpm 下约 0.2 转） |
| 重采样 | 无 |

**对稿件的含义**：相同的 1024 点在三个数据集中对应的机械观测时长差异达 5 倍，PU / JNU 的窗口短于一转，故障冲击不一定出现在每个窗口中。因此"PU 比 CWRU 对噪声更敏感"只能写成**当前处理协议（固定 1024 点、逐窗口归一化）下的观察**，不能归因于数据集本身。
