# 预注册 E5：损伤尺寸与文件身份的识别实验（审稿意见 3）

> 2026-09-25，写于任何 E5 训练之前。触发：模拟审稿意见 3——CWRU"尺寸覆盖效应"尚未与文件身份、负载、个体缺陷分离；"只用 0.007″ vs 三尺寸混合"不能区分"尺寸多样性"与"加入某一种较大尺寸即可"。
> 代码：`code/e5_size_id.py`（训练函数、评估函数与 `arm2x2.py` 完全相同）；分析：`code/analyze_e5.py`（运行时校验本文件 SHA256）。
> 逐文件映射：`results/cwru40_file_map.csv`。

## 1. 文件池与测试集

- **文件池** = 40 文件切分中的 train ∪ val（共 30 个文件）；**测试集** = Test_40（10 个文件，与文件池按文件不相交，与 2×2 相同）。使用最后一轮权重，不用验证集选模，因此 val 文件可以进入文件池
- 各（类别，尺寸）在文件池中的文件（负载 hp）：
  - B：007 {0,1,3}；014 {0,1,2}；021 {0,1,2}
  - IR：007 {0,1,2,3}；014 {1,2}；021 {0,1,3}
  - OR@6：007 {0,1,2,3}；014 {0,2,3}；021 {0,2}
  - Normal：{0,2,3}

## 2. 设计

**因子 A：尺寸集合（7 个）** S007、S014、S021、S007+014、S007+021、S014+021、S_ALL。
**因子 B：文件抽取（3 次，d0 / d1 / d2）** 对每个（抽取，类别，尺寸），用 `rng([draw, class, size])` 从文件池中抽 1 个文件。**同一次抽取中，某（类别，尺寸）的文件在所有包含该尺寸的集合里相同**（配对）。Normal 文件由 `rng([draw, 0])` 抽 1 个。
**预算**：每类 230 窗，共 920 窗（与 E2 相同，保证每个单文件都够用）；多尺寸集合中每类 230 窗在尺寸间均分（115/115；77/77/76）。窗口用 `rng([seed, draw, class, size])` 无放回抽取。
**训练**：`arm2x2.train_last`，epochs = 200 → 每轮 15 个 batch，共 **3000 步**（与 2×2 相同）；类权重按训练集重算；最后一轮权重。同一种子在所有臂中初始化相同。
**评估**：`arm2x2.evaluate`，SNR {10, 0, −4, −6, −8}，5 次噪声抽样，噪声种子 `1000 + 17·seed + r`——**同一种子在所有臂中使用同一组噪声实现**。
**架构**：wdcnn、drsn、lstm（2×2 中覆盖效应成立的 3 个）。**种子**：0、1、2。
**实例数**：7 × 3 × 3 × 3 = **189**。

## 3. 结局

- 实例级：−8 dB 的**主导类别**（5 次抽样各自主导类别的众数，与 2×2 相同）与**集中度**（5 次抽样最大类占比的均值）
- 抽取级：3 个种子中主导类别为 IR 的比例 `p_IR(set, draw)`
- 集合级：`P_IR(set)` = 3 次抽取的均值

## 4. 判定（逐架构，按顺序取第一个成立的标签）

令 A = P_IR(S007)，B = P_IR(S_ALL)。

1. **NO_REPLICATION**：A − B < 0.5（在单文件抽取、920 窗预算下未复现 2×2 的 S007 → IR / 全尺寸 → OR 差异）
2. **FILE_DEPENDENT**：S007 或 S_ALL 中，任意两次抽取的 p_IR 相差 ≥ 2/3（例如一次抽取 3/3 IR、另一次 ≤ 1/3）
3. **ANY_LARGER_SIZE**：P_IR(S014) ≤ A − 0.5 且 P_IR(S021) ≤ A − 0.5（单独一种较大尺寸即足以使靶标离开 IR，不需要多样性）
4. **DIVERSITY**：P_IR(S014) > A − 0.5 且 P_IR(S021) > A − 0.5，且三个多尺寸集合的 P_IR 都 ≤ A − 0.5（只有混合多个尺寸才离开 IR）
5. **SIZE_SPECIFIC**：S014 与 S021 中恰有一个 ≤ A − 0.5（取决于具体加入的是哪种尺寸）
6. **MIXED**：其余情况

**对稿件的后果（预先约定）**
- 3 个架构中 ≥ 2 个为 ANY_LARGER_SIZE / DIVERSITY / SIZE_SPECIFIC 中的**同一个**标签 → §4.2 以该标签措辞，仍限定"在 CWRU 文件池内"
- 否则（含 NO_REPLICATION、FILE_DEPENDENT、架构间不一致）→ §4.2 主张收窄为"**所选训练文件组成的干预效应**"，不写"损伤尺寸本身"
- 无论何种标签，都**不**写"损伤尺寸的普遍因果效应"

## 5. 次要（描述性）

- 各集合 × 抽取的主导类别分布（含 OR、Ball、Normal），不只报告 IR
- 抽取所用文件的负载组合；负载与靶标的关系只作描述
- −6 dB 下的同一判定；集中度 ≥ 0.90 的限定分析

## 6. 局限（事前写明）

- 每个（类别，尺寸）在文件池中只有 2–4 个文件，且均来自同一试验台；文件抽取只能在这些文件之间变化，不能代表"其他轴承 / 其他试验台"
- 负载无法完全固定：没有一个负载在文件池中覆盖全部 9 个（类别，尺寸）组合
- 920 窗预算与 2×2 的 1900 窗不同；与 2×2 不直接合并
- 每个抽取只有 3 个种子；抽取级 p_IR 的分辨率为 1/3
