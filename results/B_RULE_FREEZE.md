## 冻结的规则：**C-a 数据谱平坦度**

对一个训练实例的**干净训练集**（即该实例实际用于训练的全部窗口）：
1. 每个窗 x（长度 1024）：P = |rFFT(x)|²，去掉直流分量（第 0 个频点）；SF = exp(mean(log(P + 1e-20))) / mean(P)（双精度计算）。实现：`code/b_common.py::sf`、`rule_a`
2. 按真实类别求 SF 的平均值
3. **Healthy（类 0）的平均 SF 最高 → 预测宏类 Healthy；否则 → Fault**

没有可调参数。C-a 在每个确认实例**训练之前**计算并写入结果文件。
