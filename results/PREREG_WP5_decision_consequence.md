## 3. 噪声与评估

- AWGN，按窗功率（`add_awgn_tensor`，与各实验训练时的噪声函数相同）。SNR 网格：+10、+4、0、−4、−6、−8 dB
- 每个 (实例, SNR) 做 5 次噪声抽样：`torch.manual_seed(5000 + 17·seed + rep)`。所有指标先在每次抽样内计算，再对 5 次取均值
- 每个样本保存 softmax 最大值（置信度）与预测类
- 本实验的噪声种子与此前实验不同 → 崩溃靶标会重新计算；报告与此前记录的 −8 dB `top_mode` 的一致率，不据此修改任何旧判定

## 4. 决策与指标

**决策规则**：每个窗 → {接受并输出预测类，拒识（送人工检查）}。拒识不计为错误。

**三种决策基线**（阈值在看任何带噪结果之前，只用**干净校准集**定死）：
1. **B0 不拒识**
2. **B1 信号质量拒识**：谱平坦度 SF（功率谱几何均值 / 算术均值，Welch 法不用，直接对窗做 rFFT 功率谱，去掉直流）。阈值 = 该数据集干净校准集上 SF 的 **99 百分位**（与模型无关）；SF 高于阈值 → 拒识
3. **B2 置信度拒识**：每个实例单独定阈值 τ = 该实例在干净校准集上 softmax 最大值的 **5 百分位**（干净数据拒识 5%）；置信度低于 τ → 拒识

**校准集**：CWRU 40 文件切分与 16 文件 v2 切分的 `val`；PU 为每个文件时间切分中未使用的中段 20%（训练段末 + 间隔 之后的 20%，与训练、测试段都不重叠）。

**指标**（按类平衡，不受测试集类构成影响）：
- **FAR** 误报率 = 健康窗中"被接受且判为任一故障类"的比例
- **MFR** 漏报率 = 故障窗中"被接受且判为健康"的比例
- **HER_bal**（**主指标**）= ½(FAR + MFR)：改变"停机 / 不停机"决策的错误
- **WTR** 故障类型错判率 = 故障窗中"被接受且判为另一故障类"的比例（改变维修动作，不改变停机决策）
- **REJ** 拒识率；**SILENT** 静默率 = 被接受的错误样本占全部错误样本的比例（B2 下衡量"置信度监控能否发现崩溃"）

## 5. 预注册假设与判定

**主结局**：B2（置信度拒识）下、−8 dB 的 HER_bal。效应界 **δ = 0.20**（与 2×2、WP2 相同）。
统计单位 = 训练实例。F1：每架构 10 vs 10 独立实例，差值的 95% bootstrap CI（10 000 次，按侧重抽实例）；F2：每架构 5 对配对实例，配对差的 95% bootstrap CI。

每个因子 × 主架构：
- **MATTERS**：|Δ HER_bal| ≥ 0.20 且 CI 不含 0
- **EQUIV**：CI 完全落在 (−0.20, +0.20) 内
- 其余：UNDETERMINED

因子级标签：
- **H5-F1 / H5-F2 = DESIGN_MATTERS**：≥ 2/3 主架构为 MATTERS，且方向一致
- **= NO_CONSEQUENCE**：≥ 2/3 主架构为 EQUIV
- 其余：**INDETERMINATE**

**H5-S（静默性）**：F1、F2 的全部主架构实例合并，在 −8 dB、B2 下，若 **SILENT ≥ 0.50** 的实例占 ≥ 2/3 → 标签 **SILENT_UNDER_CONFIDENCE**（置信度监控发现不了多数崩溃错误）；若 ≤ 1/3 → **CAUGHT_BY_CONFIDENCE**；其余 MIXED。

**H5-G（信号质量门）**：F1、F2 全部实例，−8 dB 下 B1 的 REJ ≥ 0.95 的实例占 ≥ 90% → 标签 **GATE_NEUTRALIZES_AT_-8dB**。同时报告 **B1 的 REJ < 0.50、而 B0 的 HER_bal ≥ 0.20** 的最高 SNR（"门拦不住、错误已发生"的区间），这是描述性结果，不设判据。

## 6. 规划中的使用方式（事先写明）

- 任一因子 DESIGN_MATTERS，且 H5-G 不是"在所有出现错误的 SNR 上门都能拦住" → WP5 ✓，G1 升为 🟢 候选；稿件可考虑 RESS
- 两因子都 NO_CONSEQUENCE / INDETERMINATE，或信号质量门在所有有错误的 SNR 上都拦住 → WP5 ✗，**MSSP**，工程后果只作讨论
- **不论结果，不修改 WP2 判定，不恢复 Nature 外推主张**

## 7. 事前预期（写下来，便于事后对照）

- F1：CWRU 的两种构成都崩向**故障类**（IR 或 OR），因此两者对 HER_bal 的影响可能相近（都主要表现为健康窗的误报），**F1 的效应更可能出现在 WTR（报错的故障类型）而不是 HER_bal** → H5-F1 预计 NO_CONSEQUENCE 或 INDETERMINATE
- F2：cnn1d 的 best checkpoint 崩溃、第 100 轮不崩溃，可能出现 MATTERS；wdcnn / drsn 完整训练后崩溃更广，方向与 cnn1d 相反 → "方向一致"条件可能不满足
- H5-S：崩溃即单一类预测，预计置信度高 → 倾向 SILENT
- H5-G：−8 dB 下谱平坦度很可能几乎全部拦住 → 工程意义取决于中等 SNR 区间

## 8. 已知局限

- 噪声为合成 AWGN；真实现场噪声的谱形不同，B1 的效果可能被高估
- 选模协议因子只有 CWRU 16 文件配置（JNU 无早期 checkpoint，见 WP1）
- F1 的测试集 Test_40 对 C007 臂部分分布外（+10 dB 准确率 0.74–0.76），见 `VERDICT_2x2` §2.3
- 统计单位是训练实例，不跨架构做合并检验
