# 阶段 1′ 判定：下界命题在第二个数据集上被强否证

> 2026-08-26。预注册判据见 `analyze_variance_share.py`（在看 PU 数据前定死）。
> 中间判定：PU 扫掠 16/25 已落盘（transformer 每 run 68 分钟，drsn 未跑完）。

## 判定

**V4_STRONG_FALSIFIED。**

| | JNU-a (n=22) | PU (n=16) | PU 平衡子集 (n=15) |
|---|---|---|---|
| 架构份额 | 12.7% | **56.8%** | **55.8%** |
| 种子份额 | 48.1% | **6.7%** | **11.2%** |
| 残差 | 39.1% | 36.5% | 33.0% |
| 判定 | V2_PARTIAL | **V4** | **V4** |

平衡子集 = 只取满 5 种子的 cnn1d/lstm/wdcnn，排除 transformer 单点
造成的架构份额虚高。**判定不变**，所以结论不是设计不平衡的产物。

## 命题状态

被否证的命题（阶段 0′ 的产物）：

> 不存在只依赖设计（架构、维度、$c=p/n$）的量，能预测崩溃起始 SNR。

**PU 上存在。** 架构解释 56% 的 onset 方差，而种子只有 7%。
最直接的证据在架构内跨度：

| | PU | JNU-a |
|---|---|---|
| lstm | **1 dB** | 6 dB |
| wdcnn | 3 dB | **12 dB** |
| cnn1d | 6 dB | 3 dB |

PU 的 lstm 五个种子 onset 全落在 −1 dB 附近。**架构在 PU 上是稳定的
预测量**——这正是下界命题断言不存在的东西。

## 这不是"JNU 错了"，是命题的量化形式错了

两个数据集都是真的。真实情况是：

> **设计因子的预测力是数据集依赖的，不是普遍缺失的。**

原命题（下界形式）断言"任何数据集上都不存在设计侧预测量"，
这被 PU 单点否证——下界命题只需一个反例即倒，这是它作为
不可能性断言的代价，也是它当初显得强的原因。

## 副发现：崩溃的拓扑不同

崩溃格序列（高 SNR → 低 SNR，X=崩溃）：

| | 崩溃后又恢复的 run |
|---|---|
| JNU-a | **1 / 25** |
| PU | **3 / 4**（前四个已查） |

JNU 是单调进入崩溃后保持；PU 是"进入又退出"的**窗口**。
例：`cnn1d s3` = `.....XXXXX.....`——只在 −2 到 −6 dB 之间崩溃，
更低 SNR 反而不崩。

机制解释（**未检验**，仅记录）：低 SNR 下噪声把"全押一类"的
输出分布打散，浓度掉回阈值以下。若成立，则"崩溃"在 PU 上是
一个**有界区间**而非半轴，`onset`（首次崩溃）捕捉的是区间左边缘——
定义一致，但语义与 JNU 不同。

这一条比方差份额更值得追，因为它是**结构性的跨数据集差异**，
而不是一个份额数字。

## 已排除的替代解释

| 解释 | 检验 | 结果 |
|---|---|---|
| 设计不平衡致架构虚高 | 只取满 5 种子的 3 架构重算 | 判定不变（55.8% vs 11.2%）|
| 右截断（网格顶端不够高）| 查 +6 dB 档 | 16 run 全部未崩，onset 有效 |
| 欠训（如 JNU 冒烟档）| val 准确率 | 0.95–0.98，与 JNU ≥0.999 同量级 |
| 泄漏 | 双重检查（时间 gap + 组不重叠）| 双重通过 |
| 类不平衡（判定风险 2）| PU 严格平衡 | 不平衡比 1.000 vs JNU 3.005 |

**风险 2 反而被证实为关键**：JNU-a 的 87.3%/48.1% 有可能就是
类不平衡（3.005）的产物。PU 平衡后种子份额掉到 7%。这不能证明
因果，但它是目前最强的候选解释，**且当初的判定把它列为风险是对的**。

## 下一步的三个选项（未裁定）

1. **追崩溃拓扑差异**。JNU 单调 / PU 窗口，这是新的、结构性的观察。
   成本：低（已落盘数据即可分析）。风险：可能只是阈值定义的产物。
2. **测"类不平衡 → 种子份额"这条因果**。把 JNU-a 人工平衡成 1.000
   重跑，看种子份额是否从 48% 掉下来。成本：低（约 1 小时）。
   这会把一个副产物变成主结论：**方差归属由类不平衡决定**。
3. **放弃这个方向**。三轮否证后，正面结论只剩"份额是数据集依赖的"，
   这不够上正刊。

我倾向 **2**——它是唯一一个能把三轮否证收拢成一个正面机制断言的，
而且便宜。但这是你的裁定。
