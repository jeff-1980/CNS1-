# Renewable Energy 投稿操作说明（AeroUp 论文）

投稿系统：Elsevier Editorial Manager（Renewable Energy 主页 → Submit your article）。文章类型选 Research Paper。

## 上传文件对照（推荐 LaTeX 方式）
| 系统里的文件类型 | 上传本目录的文件 |
|---|---|
| Cover Letter | cover_letter.docx（先填日期） |
| Title Page (with author details) | title_page.docx |
| Highlights | highlights.docx |
| LaTeX Source File | latex/manuscript.tex |
| Manuscript（系统要求 PDF 时） | latex/manuscript.pdf（elsarticle 排版，带行号，31 页） |
| Figure | latex/figures/fig1_design.pdf … fig7_replication.pdf（每张单独上传，顺序 1–7；文件名要和 tex 里一致，系统会自动编译） |
| Graphical Abstract | figures/graphical_abstract.png（1992×796 px，满足 ≥1328×531） |
| Supplementary Material | supplementary_material.docx（表 S1、图 S1–S5） |

如果系统编译 LaTeX 报错，可以退回 Word 方式：Manuscript 换成 manuscript.docx（内容与 LaTeX 版一致，同样 50 条参考文献）。latex_source.zip 是同一套文件的打包，仅备份用，系统里不要上传 zip。

参考文献：50 条（期刊上限 50），新增的 30 条 DOI 都在 Crossref 逐条核对过，按正文首次出现顺序编号。正文约 5,920 词（限 4,000–6,000），摘要 231 词。
