## 研究问题
AeroUp 叶片气动升级让发电量提高约 4%，传动链为此多付出多少疲劳暴露？用"载荷代价比" C = ΔDEL / ΔE（扭矩损伤当量增幅 ÷ 发电量增幅）作为工程决策指标。基线给出的粗估是 C ≈ 1.7% / 3.6% ≈ 0.47。

## 五个淘汰测试（任何一个 KILL 即停）

**K1 已知真值模拟（H2 补充要求，最先跑）**
在未升级机组的真实 post 数据上注入已知效应：功率乘以 1.04 并在 2300 kW 截顶，扭矩按同一功率和实测转速重算。然后用正式估计器（含漂移校正）重估。
- 判据：20 台注入后的 E 恢复值中位落在 [+3.0%, +5.0%]，满功率时间 R 和 DEL 的恢复偏差（估计值减注入真值）中位绝对值 < 0.3 pp / 0.5%。否则 KILL（方法测不准）。

**K2 漂移校正后的 T13 效应**
所有机组共用同一参考集（全部排除 T13），对 21 台逐台算 R、E、D3。T13 效应减去 20 台安慰剂的中位数（双重差分）。推断用置换检验：T13 在 21 台中的排名。
- 判据：校正后 R ≥ +1.0 pp，且 T13 的 R 排第 1（单侧置换 p = 1/21 ≈ 0.048）。否则 KILL。

**K3 2022–23 批次复制**

- 可用台数预计 8–15 台，实际数在运行前从安装日期表算出并写入冻结版。
- 判据：合并后 R 的效应 > 0 且 95% CI（台间 bootstrap）不含 0，且 ≥ 60% 的单台为正。否则 KILL（T13 可能是孤例）。

- 判据：重加权后 R 仍 ≥ +0.8 pp。否则 KILL。
